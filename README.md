# Puddle

We have compiled the major models other than text.

Those related to embeddings, images, and audio (such as Whisper and TTS) are brought together into a single catalog.

The integrated catalog is available at:

```
https://raw.githubusercontent.com/gratnics/puddle/HEAD/catalog.json
```
